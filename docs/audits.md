# Audits

An audit is a review of the Zenex contracts by an independent security firm. This page carries the report from each finished audit, with the date it finished and the contracts it covered.

## Completed audits

The contracts you trade against today are unaudited. This section stays empty until a firm finishes an audit of them.

## What an audit covers

An audit reviews the contract code as it stands on the date of the report. A change made to the code after that date sits outside that report. **Code that passes an audit can still contain defects.** Treat the contracts as capable of losing your money whether or not a report covers them. For the risks that stay with you, see [Risks](./risks.md).

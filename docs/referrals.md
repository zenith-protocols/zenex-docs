# Referrals

A referral associates a trader account with a referrer when an app offers that program. The trader authorizes an attribution naming the referrer.

## Attribution and rewards

The attribution contract publishes an event. It rejects self-referral. It can publish more than one attribution for an account. A program can choose which event it recognizes. For example, the app's attribution logic can retain the first valid referrer. Only follow a referral setup flow when the app offers it. Review the account and referrer before you sign. For how to review that action and its fee, use [What you sign](./account/signing.md).

:::info A referral record does not guarantee a reward
The attribution contract records the relationship. It does not calculate points, set a reward rate, or pay a bonus. Use the terms and availability shown for the specific program.
:::

# Referrals

A referral program is planned for Zenex and will be announced in the near future. The program will allow users to earn rewards by introducing new traders and liquidity providers to the platform, creating a direct incentive for community-driven growth.

Referral rewards will be tied to the trading activity of referred users, aligning incentives so that referrers benefit from bringing active participants to the protocol. Full details on reward structure, eligibility, and how to generate referral links will be published on this page when the program launches.

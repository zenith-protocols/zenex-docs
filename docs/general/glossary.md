# Glossary

A reference of key terms used throughout the Zenex documentation.

| Term | Definition |
|------|-----------|
| **Perpetual futures (perps)** | Derivatives contracts that let you speculate on an asset's price without expiry |
| **Notional size** | The total value of a position (collateral x leverage) |
| **Collateral** | Funds deposited to back a position and absorb losses |
| **Leverage** | Multiplier that amplifies exposure beyond deposited collateral |
| **Margin** | The minimum collateral required relative to notional size |
| **Initial margin** | Minimum collateral ratio required to open a position |
| **Maintenance margin** | Minimum equity ratio required to keep a position open |
| **PnL** | Profit and Loss — the unrealized gain or loss on an open position |
| **Equity** | Collateral + PnL - Fees; determines position health |
| **Liquidation** | Forced closure of a position when equity falls below maintenance margin |
| **Funding rate** | Periodic payment between longs and shorts to anchor perp price to spot |
| **Vault** | Liquidity pool that provides the borrowed funds for leveraged trading |
| **Vault token** | The token accepted as collateral, determined by the vault |
| **Keeper** | Permissionless actor that executes protocol maintenance actions |
